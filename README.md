# NumBanco

Projeto desenvolvido em **Java** com o objetivo de praticar os principais conceitos de **Programação Orientada a Objetos (POO)**.

## Sobre o projeto

O **NumBanco** simula operações básicas de uma conta bancária.

O projeto está sendo desenvolvido como parte dos meus estudos de Java, com foco em compreender na prática como funciona a Programação Orientada a Objetos.

## Conceitos estudados

Durante o desenvolvimento, estou praticando conceitos como:

* Classes e objetos
* Atributos
* Métodos
* Encapsulamento
* Modificadores de acesso
* Getters e Setters
* Estruturas condicionais
* Métodos de abertura e fechamento de conta
* Manipulação de saldo
* Organização de código em Java

## Funcionalidades

Atualmente, o projeto possui funcionalidades relacionadas a:

* Abrir uma conta
* Fechar uma conta
* Consultar o estado da conta
* Definir o tipo de conta
* Controlar o saldo
* Controlar o status da conta

## Objetivo

O objetivo principal deste projeto é **aprender e evoluir na programação Java**, colocando em prática os conceitos estudados e acompanhando minha evolução durante o aprendizado.
